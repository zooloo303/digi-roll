Own a box digi-roll can't read yet — Digitone, Syntakt, Analog Rytm, Analog Four? You can help map it, and nothing here ever writes to a box: this page only sends read-only requests. Connect → Probe dump protocol → post the report to the thread. If the probe finds a family byte, go further: Capture baseline, change exactly one thing on the box (add one trig, turn one knob one click), Capture + diff, write what you changed in the note, then Export pair and attach the file. Each pair teaches us one byte-level fact about your box.
