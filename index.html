digi-roll

Getting a pattern onto your Digitakt 2 / Digitone 2

  1. Connect the box via USB and pick it in the MIDI output menu.
  2. On the box: SETTINGS → MIDI CONFIG → SYNC — enable CLOCK RECEIVE and TRANSPORT RECEIVE. Leave Clock checked in this app.
  3. Set this app's Ch to the MIDI channel of the destination track (SETTINGS → MIDI CONFIG → CHANNELS on the box). Draw your notes and press Play to audition — the track's sound plays your pattern live.
  4. To capture it into the box's own sequencer: select an empty pattern on the box, enter live recording (RECORD + PLAY), then press Play here. The app sends Stop → Start + clock, which snaps the box back to step 1 in sync with bar 1 of your pattern. Let it loop once, exit record mode, done.
  5. Quantize on the box afterwards if needed. Notes longer than one step are captured with their length.

Sync rules (read this if notes land in the wrong place)

  • One clock master at a time. If your Octatrack (or anything else) is also sending clock/transport to the box, the box can't lock to this app. During capture either stop the OT's clock send, or set the Digi's SETTINGS → MIDI CONFIG → PORT CONFIG → INPUT FROM = USB so it only listens to this app — flip it back afterwards.
  • Every press of Play here sends Stop then Start, so the box restarts from its pattern step 1 — your recording always lines up with the app's bar 1.
  • Use Count-in (1–2 bars) to get a moment between arming live record and the notes arriving. Keep the count-in a multiple of the box's pattern length so the downbeats stay aligned.
  • On auto channel (default 10): notes go to whichever track is currently selected on the box — handy, just make sure the right track is active before recording.

Tips: click to draw a note and drag right to lengthen it · drag notes to move · drag a note's right edge to resize · shift+drag up/down to set velocity (brighter = harder) · cmd/ctrl+drag a note sideways for micro-timing (fractions of a step, shown as you drag) · right-click (or alt-click) to delete.

Selecting: cmd/ctrl+drag on empty grid draws a marquee · shift+click a note to add/remove it from the selection · moving, deleting, shift+drag velocity and the Vel slider all apply to the whole selection.

Keys: space = play/stop · Delete/Backspace = remove selected · cmd/ctrl+Z undo, shift+cmd/ctrl+Z redo · cmd/ctrl+C / X / V copy, cut, paste (the clipboard follows you between pattern slots). Swing is per pattern (50 = straight); the scale menu only tints rows, it never restricts what you can draw. Patterns auto-save in your browser.

Straight into pattern memory (no live recording)

  • The device console talks SysEx to a Digitakt 2 or Digitone 2 directly: back up the project, import a pattern's track into a roll slot, write a roll slot into any pattern track, or copy a track from one pattern to another — even between the two boxes, via a saved .syx backup.
  • Once a slot has been imported, Write back here sends your edits straight home to the pattern and track they came from. It re-reads the pattern first, downloads a backup of it, changes only that track's notes, then reads it back and checks every byte. Anything else on the box — sounds, p-locks, other tracks — is left alone.
  • Write back only lights up for imported patterns, and only writes to the same box they came from, on an OS build the format has been verified against.
  • Bank keeps named saves of your patterns in this browser (with swing, micro-timing and where they came from), and exports them as .json to share or back up.
